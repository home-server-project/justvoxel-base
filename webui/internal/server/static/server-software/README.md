# Server software artwork

One local asset directory is shared by Recommended Setup, Advanced Setup and
the Version workspace. Render artwork proportionally on transparent backgrounds.

- `paper.svg`: unmodified official square Paper symbol from the PaperMC website
  repository, https://raw.githubusercontent.com/PaperMC/website/main/src/assets/brand/paper.svg.
  Usage terms: https://docs.papermc.io/misc/assets/ (permits server selectors;
  preserve colors, proportions, artwork and transparency). The transparent SVG
  is bundled locally and shared by both setup modes and the Version workspace.
- `purpur.svg`: unmodified artwork from PurpurMC/PurpurWebsite,
  https://raw.githubusercontent.com/PurpurMC/PurpurWebsite/master/public/images/purpur.svg,
  retrieved through read-only GitHub access. Copyright (c) 2019-2025 PurpurMC.
  The repository MIT license is retained in `Purpur-LICENSE.txt`.
- `vanilla.svg`: original JustVoxel grass/dirt block illustration, created for
  this selector. No Minecraft, Mojang or third-party artwork was copied.

These names identify their respective projects; they do not imply endorsement.
