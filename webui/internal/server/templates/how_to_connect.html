Join with Java Edition

  1. Open Minecraft Launcher and start Minecraft: Java Edition.
  2. Choose Multiplayer.
  3. Choose Add Server.
  4. Enter a server name — any name you like.
  5. Use one of the Java connection addresses shown above in Server Address.
  6. Choose Done, select the server and choose Join Server.

For a quick visit, choose Direct Connection instead of Add Server, enter the same Java address and choose Join Server.

{{if eq .ConnectionGuide.JavaPort 25565}}

For methods using the configured Java port, Minecraft normally lets you omit :25565. Keep any explicit public Playit port shown above.

{{else}}

For methods using the configured Java port, enter address:{{.ConnectionGuide.JavaPort}}. For Playit, use its exact public Java address above.

{{end}}
{{if .ConnectionGuide.Bedrock}}

Join with Bedrock Edition

For Windows, iPhone, iPad and Android.

  1. Open Minecraft Bedrock Edition.
  2. Choose Play.
  3. Open Servers.
  4. Choose Add Server.
  5. Enter a server name and one of the Bedrock addresses shown above.
  6. Enter that method’s corresponding Bedrock port.
  7. Choose Add, then Play.

Java and Bedrock ports may differ. Use the Bedrock address and port together; Playit can use a different public port.

If a selected method has only Java information, choose another method for Bedrock.

PS5 · Method 1: BedrockConnect DNS

  1. Open PS5 Settings → Network → Settings → Set Up Internet Connection.
  2. Highlight your active Wi-Fi or wired connection and open Advanced Settings.
  3. Change DNS Settings from Automatic to Manual.
  4. Set Primary DNS: 45.55.68.52 and Secondary DNS: 8.8.8.8.
  5. Save and wait for the network test.
  6. Open Minecraft → Play → Servers.
  7. Open a compatible featured server to reach the BedrockConnect list.
  8. Choose Connect to a Server / Add Server.
  9. Enter one of the enabled Bedrock addresses and its matching port from this guide.

The PS5 DNS address is not the Minecraft server address. DNS helps you open the server list; use a Bedrock connection address from this guide to join Minecraft.

If PS5 internet stops working, restore DNS Settings → Automatic and use the phone method below.

PS5 · Method 2: BedrockTogether phone app

  1. Connect your phone and PS5 to the same home router/network. Disable cellular data and VPN on the phone while testing.
  2. Install BedrockTogether for Minecraft on iPhone or Android.
  3. Allow the required Local Network / nearby-device permissions.
  4. Enter one of the Bedrock addresses in this guide and its matching port.
  5. Choose Start / Run in BedrockTogether and leave it open.
  6. On PS5, open Minecraft → Play → Friends.
  7. Look under LAN Games and join the server that appears.

After joining successfully, the phone app can normally be closed.

If the server does not appear: avoid guest Wi-Fi and mobile hotspots; turn off VPN and iCloud Private Relay while testing; keep BedrockTogether running; restart Minecraft once if necessary.

Tailscale and NetBird still require access to the relevant private network on the connecting device. These PS5 methods do not grant that access.

{{end}}

“You are not whitelisted”

If Minecraft says the player is not whitelisted, the network connection succeeded.

Send the server owner your exact Minecraft gamertag and a clear screenshot/photo of the message.

Having trouble joining?

  • Check the correct Minecraft edition and selected connection method.
  • Check the address and the corresponding Java{{if .ConnectionGuide.Bedrock}} or Bedrock{{end}} port.
  • Update Minecraft and restart it once.
    • {{if .ConnectionGuide.Bedrock}}
  • For PS5 DNS problems, restore DNS Settings to Automatic.
    • {{end}}

If it still fails, send the server owner your exact error screenshot, exact Minecraft gamertag, device type, {{if .ConnectionGuide.Bedrock}}Java or Bedrock edition{{else}}Minecraft edition{{end}}, and the connection method used.
