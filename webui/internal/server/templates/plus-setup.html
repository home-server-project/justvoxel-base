What would you like to install?

Panel manages your game servers. These components provide its infrastructure.

Manage the infrastructure containers. Game containers remain in Pterodactyl.

The complete stack and Drydock are selected by default. You can change each component.

A partial stack may need your own external services and configuration before it works.

How will you open the applications?

Use an address reachable from your browser and Wings. Set up DNS for your domain separately.

Optional. Supply a PEM certificate chain and matching private key for this address.

Without a certificate, application connections use HTTP. Use a trusted local network.

Where should application data live?

Default: system storage at /var/lib/justvoxel-plus.

Stores application configuration, database data and Pterodactyl game files.

Docker's image storage stays on the system disk. No disk is formatted and no backup system is created.

A second disk must stay mounted after restart. Removable drives are unreliable for running containers. Use Storage on the desktop to prepare a disk first.

Application administrator

Enter your current password here if you want the same credentials. The login password is not stored for reuse.

Panel and Drydock start with these credentials. These are separate accounts. Changing your password in one does not change the other.

No Panel or Drydock account is needed for the selected components.
