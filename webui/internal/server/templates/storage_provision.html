Option 1

Dedicated disk or USB drive

Entire disk

Use a whole unused disk as backup storage. System disks and disks with mounted filesystems are excluded from this list.

{{if .WholeDisks}}
Review does not modify the disk.
{{else}}
No safe unused whole disk is currently available. Attach a second disk/USB device or choose another storage method.

Option 2

Format a blank partition

Selected partition only

Use a writable partition that currently has no detected filesystem. Existing formatted filesystems belong on the normal Backup storage page and are never reformatted here.

{{if .BlankPartitions}}
The selected partition will become XFS only after typed confirmation.
{{else}}
No writable blank partition is currently available.
{{end}}

Option 3

Use already-unallocated disk space

No shrinking

Create a new XFS partition only in existing unallocated space. JustVoxel never shrinks, moves, or resizes an existing partition or filesystem.

{{if .FreeSpaceDisks}}
Review shows the exact free-space range before anything changes.
{{else}}
No disk currently has an unallocated segment of at least 1 GiB.
{{end}}
