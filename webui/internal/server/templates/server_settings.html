Minecraft memory

{{.SystemMemory}} detected

JustVoxel itself typically uses roughly 0.6–1.0 GiB during normal operation. Memory left outside Minecraft is not reserved; Linux can use it for filesystem cache, backups, updates, management services and temporary workload spikes. {{.SystemReserveRecommended}} is the recommended headroom and {{.SystemReserveMinimum}} is the enforced minimum.

Presets use detected system memory and the maximum-player setting below. Each additional block of 10 players increases the suggested Minecraft memory until the home-server preset caps are reached. Large public servers should use Custom and tune for their workload.
