Automation / REST API

Use the REST address and JustVoxel connection token.

AI provider cards use the MCP connection address. Automation / REST API uses the REST API address.

Support and setup availability depend on the provider, application, account, plan or subscription, and network access.

Create a connection, copy its JustVoxel connection token once into your app, then select Done.

Access levels

Level 1 — Read Only

Can see server information. Cannot change anything.

Level 2 — Basic Management

Can perform common safe actions such as restarting a Minecraft server and creating a backup. Stop is not included. Restart and backup allowances and cooldowns apply.

Level 3 — Full Management

Can manage Minecraft servers and normal JustVoxel administration features.

Level 4 — Full System Control

Advanced mode. Can control important parts of the host system. Only enable this for a connection you fully trust.

No level can manage connection permissions, user accounts or Full Factory Reset.

Remote access and security

Local JustVoxel uses HTTP on your trusted local network by default. Use HTTPS or a private VPN such as Tailscale for protected remote access. Never expose port 8099 directly to the public Internet.

JustVoxel does not require an AI provider model API key merely to expose MCP or REST.

Developer integration

OpenAPI: (requires your connection credential).

OAuth protected-resource metadata: . Required scope: justvoxel:connect.

MCP uses Streamable HTTP with a bearer credential. Your app must support this protocol and the configured token or OAuth method.

OAuth requires HTTPS issuer, JWKS and resource addresses, plus a subject or client binding. JustVoxel checks tokens from your configured sign-in service; it does not issue OAuth tokens.

When using a trusted HTTPS reverse proxy, preserve the external Host and forward X-Forwarded-Proto: https for correct discovery.

Optional expiration stops access at the chosen time. Leave it empty for no connection expiration; OAuth access tokens still need their own valid expiration.
